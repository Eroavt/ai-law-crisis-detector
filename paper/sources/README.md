# paper/sources/ — author-side citation working directory

This directory is the author's local working store for source PDFs used to verify the Swiss-commentary citations in the paper. The PDFs themselves are **not committed** to the public repository because they are copyrighted material (Schulthess / Stämpfli / Orell Füssli / Helbing Lichtenhahn / etc.) accessed through the UZH-licensed LexCampus database.

## How to verify the citations independently

A reader who wishes to verify any commentary citation against the original work can do so via:

- **LexCampus** (UZH-affiliated researchers): https://www.lexcampus.swisslex.ch — search the work and article. UZH login required.
- **swisslex.ch** (general subscribers): https://www.swisslex.ch — same coverage, paid access.
- **Print copies**: UZH Rechtswissenschaftliche Bibliothek, Treichlerstrasse 10, 8001 Zürich. Reading-room access; no checkout.
- **Federal Council Auslegeordnung 2025** (open access): https://www.bakom.admin.ch — search for "Auslegeordnung zur Regulierung von künstlicher Intelligenz".
- **DSI Position Paper 2021** (open access): https://www.dsi.uzh.ch — search for "A Legal Framework for AI".
- **Court records (free)**: bger.ch for BGE / BGer; pacer.gov for US complaints (*Garcia*, *Raine*, *Gavalas*, *Peralta*).

## Why these PDFs are not in the public repository

Republishing copyrighted commentary PDFs to a public GitHub repository would violate the licence terms of the publishers (Stämpfli, Schulthess, Orell Füssli, etc.) and the LexCampus terms of use. The publication-quality citations in the paper bibliography reproduce the publisher, edition, year, ISBN, and paragraph numbers needed for any reader to locate the original work.
